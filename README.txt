英検準1級 英単語クイズ（全1,079語）

使い方：
1. このフォルダで python -m http.server 8000 を実行
2. PCブラウザで http://localhost:8000 を開く
3. スマホからは同じWi-Fi上のPCのIPアドレス:8000にアクセス、またはGitHub Pages等に公開

収録データ：words.json に全1,079語と日本語訳
学習履歴：ブラウザのlocalStorageに保存。履歴画面からバックアップ可能。
注意：日本語訳は自動作成であり、全件の辞書照合は未実施です。

単語一覧・編集：
「単語データ管理」で全単語と訳を閲覧・検索できます。
「単語CSVを書き出す」は保存済みの全単語をUTF-8 BOM付きCSV（word,meaning）で出力します。
CSVの読み込みには対応していません。カンマ・引用符・改行はCSV形式でエスケープし、
表計算ソフトで数式になる可能性のある値には先頭にアポストロフィを付けます。
初回は専用パスワード（8文字以上）を設定し、以後そのパスワードで編集を解除します。
単語・訳を編集して「変更を保存」を押すと、そのブラウザのクイズに反映します。
空の訳は出題されません。空の単語・単語の重複は保存できません。
単語名を変更しても、以前の名前の学習履歴は移動・削除しません。
JSONによる既存単語の訳の取り込みも編集解除後に利用できます。
パスワードの平文は保存せず、ソルト付きPBKDF2-SHA256で検証します。
これはブラウザ内の簡易ロックで、認証サーバーによる管理者認証ではありません。
HTTPS（GitHub Pages）またはlocalhostが必要です。
保存キー：pre1-quiz-word-list-v2（編集済み一覧）、pre1-quiz-admin-v1（パスワード設定）。
既存の履歴キー・旧単語設定は維持し、編集済み一覧がある場合はそれを優先します。
編集済み一覧は公開側words.jsonの更新より優先され、他の端末・利用者には反映されません。
パスワードを忘れた場合は先に履歴・単語JSONをバックアップしてください。
このサイトのブラウザ保存データを削除すると再設定できますが、履歴と編集も失われます。
